## About

I’m a software developer from Thailand with a strong interest in programming, networking, and cybersecurity.

I got into technology at a young age through a hand-me-down notebook from my sister. What started as curiosity about computers and networks eventually grew into a passion for building software and understanding how systems work under the hood.

Since 2020, I’ve been building and maintaining real-world projects across game servers, web applications, backend systems, and infrastructure. I enjoy learning new technologies, solving problems, and turning ideas into reliable software.

---

## Experience

My experience spans software development, server infrastructure, and security, with a strong focus on practical systems that need to work reliably in production.

* **KongProject — Founder:** Founded and lead a development group where I work on projects across different technologies, from backend services and web platforms to game server systems.
* **SA:MP Development — Since 2020:** Built and maintained SA:MP servers using Pawn and MySQL, including backend systems, gameplay mechanics, server infrastructure, and core systems for projects such as GTA Career, Play Training, SiamCity, and FreeStyle.
* **Web & Platform Development:** Built platforms such as TMWPond with automated game credit delivery, payment processing, Cloudflare Turnstile protection, and real-time order tracking.
* **Infrastructure & Security:** Managed VPS infrastructure, deployments, and DDoS mitigation for hosting environments, with a focus on reliability, performance, and network security.
